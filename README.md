# 🍅 Pomodoro App

A clean, minimal Pomodoro timer built with Electron.

## Features
- 25-minute work sessions
- 5-minute break sessions
- Circular progress ring
- Session tracking

## Getting Started

### Prerequisites
- Node.js (v18+)

### Installation
git clone https://github.com/username/pomodoro-app.git
cd pomodoro-app
npm install
npm start
